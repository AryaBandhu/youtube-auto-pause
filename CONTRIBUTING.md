# Contributing

This is a standalone Chrome Extension with no build process or test suite. Contributions are welcome. Basically this is also forked from https://github.com/AryaBandhu/youtube-auto-pause.

1. Fork the repository.
2. Create a feature branch for your change.
3. Make your changes in the relevant files.
4. Test manually against the testing checklist below.
5. Open a pull request with a clear description of what you changed and why.
